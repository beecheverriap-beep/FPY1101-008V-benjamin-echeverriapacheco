# Ejercicios de Python

Este proyecto contiene dos ejercicios en Python para practicar la entrada de datos, la validación y la lógica de control.

## Archivos

- `ejercicio.py`
  - Simula un registro de médicos.
  - Pide el número total de médicos y los datos de cada uno.
  - Valida que el nombre tenga al menos 6 caracteres y no contenga espacios.
  - Clasifica a los médicos como especialidades junior (0-5 años de experiencia) o senior (más de 5 años).
  - Muestra el total de médicos junior y senior.

- `ejercicio2.py`
  - Implementa un menú para gestionar préstamos de libros.
  - Permite ver libros disponibles, prestar libros, devolver libros y ver el historial de préstamos.
  - Controla el stock máximo de libros y valida que las entradas sean números enteros.

## Cómo ejecutar

Abre una terminal en la carpeta `prueba 3` y ejecuta:

```bash
python ejercicio.py
```

o

```bash
python ejercicio2.py
```

## Notas

- Los programas usan `input()` para leer datos desde la consola.
- Se recomienda usar Python 3.
- Si ingresas un valor inválido, el programa mostrará un mensaje de error y pedirá la entrada nuevamente.
